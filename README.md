# GenAI Mini Projects

A hands-on collection of 15 Generative AI projects, progressing from the fundamentals of Large Language Models to advanced Agentic AI systems.

## About This Repository

This repository documents my practical learning journey in Generative AI. Each project focuses on implementing concepts, building working applications, and understanding how modern AI systems work.

- Python
- PyTorch
- Hugging Face
- LangChain and LangGraph
- Vector Databases
- Retrieval-Augmented Generation (RAG)
- Model Context Protocol (MCP)

## Repository Structure

Each project has its own numbered folder containing its source code, documentation, and required resources.

## Learning Approach

- Build practical projects.
